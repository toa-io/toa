# Migrating from 1.0.0-alpha.332

## `censor` is a list of countries, read from `exposition.country`

The country a request comes from is read once, by the gateway, from the header `exposition.country`
names — as the address is read from `exposition.ip` — and `censor` lists the countries it refuses.
A context that still declares `censor` with `header` and `values` fails the deploy.

```yaml
# context.toa.yaml — before
exposition:
  censor:
    header: cf-ipcountry
    values: [RU, IR]
```

```yaml
# context.toa.yaml — after
exposition:
  country: cf-ipcountry
  censor: [RU, IR]
```

1. Move `censor.header` to `exposition.country`, and `censor.values` to `censor`.
