# Migrating from 1.0.0-alpha.298

## A component may not declare `REGION`

`REGION` is a system property, beside `id`, `VERSION`, `CREATED`, `UPDATED` and `DELETED`. A
component that declares one of its own no longer builds:

```
System property 'REGION' cannot be overridden
```

Rename the property. It may not be named in `blank` either.

## A system property is no longer optional

The five are declared `required`, so a component's generated types hold them rather than
`T | undefined`. A component written in TypeScript that checks one for absence stops
typechecking:

```
This comparison appears to be unintentional because the types 'number' and 'undefined' have no overlap.
```

Delete the check. A record has always carried them.

## An unknown endpoint raises a code, not an assertion

Invoking an endpoint a component does not provide rejects with `EndpointException`, code `402`,
where it used to reject with an `AssertionError` carrying `code: 'ERR_ASSERTION'`:

```
EndpointException: 'greet' is not provided by 'basic.greeter'
```

Anything that caught the assertion, or matched `ERR_ASSERTION`, matches a number now. It is a
permanent failure, so a task or an event that hits one is set aside on the first delivery rather
than tried again.

## A schema error is Ajv's own

`better-ajv-errors` rewrote the message and the field name of every schema error. It is gone, so
what a caller reads is what Ajv wrote:

```
must have required property 'name'
```

A test or a client matching on the old text stops matching. `instancePath`, `keyword` and
`params` are unchanged and are what to match on instead.

## A call that has gone round in a circle is refused

A call carries the chain of hops it came by, and one that has been where it is going three times
is refused with `LoopException`, code `500`, whether it travelled as a call, an event, a task or a
delayed call:

```
LoopException: 'default.orders.place' is hop 3 of this chain
  trail: default.orders.place > ~default.orders.sync > default.billing.charge >
         ~default.billing.sync > default.orders.place
```

Two shapes that used to run now stop. A receiver that writes back to the component whose event it
is on is a circle, and the `~` hops in the chain name the subscription to rewire. And an operation
that arms a delayed call to its own endpoint is a circle too — where the recurrence is meant, say
so:

```javascript
await context.delay(endpoint, request, { interval, overdue: null, detached: true })
```

`TOA_TRAIL_REPEATS=0` refuses nothing, for a deployment that needs its old behaviour while it is
fixed. See [call cycles](/documentation/cycles.md).

## What to do

1. Match a number where a caller caught an `AssertionError` from an unknown endpoint.
2. Match `instancePath`, `keyword` or `params` where a test read the text of a schema error.
3. Rename an entity property called `REGION`, and delete a check for a system property being
   absent.
4. Add `detached: true` to a delayed call an operation arms to its own endpoint, and rewire a
   receiver that writes back to the component whose event it is on.
