# Migrating from 1.0.0-alpha.313

## An inbox window is ten minutes at least

`inbox.retention` in a context is refused under `600`, where anything from `1` was accepted. So is
the window an operation may now state as the value of `once` — see
[the inbox](/documentation/inbox.md). The broker alone repeats a call for up to about ten minutes,
and a shorter window misses duplicates the runtime itself makes.

The calls already remembered need nothing: each expires when it would have.

## Trailers are written into `TRAILERS`

What a transition hands to the event of its commit is written into `state.TRAILERS`, where it was
`state._trailers`. The event still carries it as `trailers`, so an event bridge that reads
`event.trailers` is unchanged.

```js
export function transition(input, object) {
  object.TRAILERS.inc = input.inc

  return object
}
```

A transition that still writes into `_trailers` throws `Cannot set properties of undefined`.

`TRAILERS` is a system property: a component that declares an entity property of that name no
longer builds, and it may not be named in `blank`:

```
System property 'TRAILERS' cannot be declared
```

## Realtime is served by the gateway

The realtime extension is gone. Its streams are served by the exposition gateway, and the events
they carry are written by the components that route them — see
[realtime streams](/extensions/exposition/documentation/realtime.md). Routes are declared as they
were, in a manifest or in the context, and `GET /realtime/streams/:identity/` reads as it did.

What changes for a deployment:

- nothing runs for realtime of its own, so `realtime.resources` in a context is refused;
- a context whose components route events names a Redis in the `stash` annotation — the address
  `realtime.streams` resolves to — which the gateway and those components reach;
- `expire`, configured on the `realtime.streams` component before, is `exposition.realtime.expire`.

An operation that answered with `context.remote.realtime.streams.create(...)` to hand its caller a
stream declares the stream on its route instead, and returns what it returns:

```yaml
exposition:
  /:identity:
    auth:id: identity
    POST:
      endpoint: connect
      realtime:stream: identity
```

## What to do

1. Raise `inbox.retention` to `600` or more where a context states less.
2. Replace `_trailers` with `TRAILERS` in every transition.
3. Rename an entity property called `TRAILERS`, and the field the collection holds with a
   [migration](/documentation/component/declaration.md#migrations).
4. Remove `realtime.resources` from the context, and move a configured `expire` of
   `realtime.streams` to `exposition.realtime.expire`.
5. Make sure the `stash` annotation names a Redis for `realtime.streams` where components route
   events.
6. Replace a call to `realtime.streams.create` with `realtime:stream` on the route that made it.
