# Migrating from 1.0.0-alpha.325

## An error is `new Error('CODE', { cause })`

An operation refused by returning an `Error` with a `code` property, and whatever else was
enumerable on it reached the caller. The code is the error's message now, and `cause` is the only
other thing that travels:

```javascript
// before
return new (class extends Error {
  code = 'LOCKED'
  message = 'Locked until the new year'
  until = '2026-01-01'
})()

// after
return new Error('LOCKED', { cause: { until: '2026-01-01' } })
```

An `Error` returned with an empty message — which is what the class above is, once its `message`
field is gone — is an exception, in every environment.

A caller reads `code` and `cause`. `message` repeats the code, and no other property is there:

```javascript
if (reply instanceof Error && reply.code === 'LOCKED') reply.cause.until
```

`cause` travels as JSON, so it is a value JSON can hold.

## A code is a string

`errors` in a manifest lists strings. An integer code is written as one:

```yaml
errors: ['0'] # was [0]
```

## `RemoteError` is `CodedError`

```typescript
import type { CodedError } from '@toa.io/core/types' // was RemoteError
```

`toa types` writes the new name, so generated types follow by running it.

## A refusal over HTTP is `{ code, cause }`

The `422` body carried the error's enumerable properties, `message` among them where it was
declared. It carries `code`, and `cause` where the operation gave one. The errors of the
components Toa ships — identity, octets, configuration — have no text any more: a client reads
the code. Where the gateway answered an octets upload, a JSON-RPC call or an MCP tool call with
an error's message, it answers with its code.

## What to do

1. Rewrite every returned error as `new Error('CODE')`, moving what else it carried into `cause`.
2. Where a caller read a property of an error, read it from `cause`.
3. Write integer codes in `errors` as strings.
4. Replace `RemoteError` with `CodedError`, and run `toa types`.
5. Where an HTTP client read `message` from a `422`, read `code`.
