# Migrating from 1.0.0-alpha.326

## A safe operation calls only what reads

An observation or a computation that calls a transition, an assignment, an effect or an unmanaged
operation, or arms a delay, is refused on that call, and so is every unsafe call below it:

```
SafetyException: 'default.orders.place' may change state, and this call may only read
```

An operation that makes such a call is declared an effect:

```yaml
operations:
  place:
    type: effect # was computation
```

Over HTTP a route to a safe operation that reaches a write answers `500`, whatever its method.

## A retried transition does not call what is made once

A transition declared `concurrency: retry` that calls an operation declaring `once` is refused on
that call, on every attempt, the first included:

```
UnrepeatableException: 'default.wallets.charge' is made once, and a transition retried on a lost write would make it again
```

Declare the transition `concurrency: none`, make the call from a receiver of the event its change
publishes, or call both from an effect. An operation that is safe to repeat by what it is needs no
`once`.

## A value compared with an array is read as what the array holds

A criterion on an array of numbers, integers or booleans reads its value as one, so `ranks==five`
is refused with `QuerySyntax`, `400` over HTTP, where it matched nothing.

## A sort or a projection names what the entity declares

A sort or a projection naming what every object carries, such as `constructor`, is refused where
it was passed to the storage.

## What to do

1. Declare an effect every observation or computation that calls what may change the State, or
   arms a delay.
2. Where a transition declared `concurrency: retry` calls an operation declaring `once`, declare
   it `concurrency: none`, or move the call to a receiver or an effect.
3. Compare an array of numbers, integers or booleans with a value of its kind.
