# Migrating from 1.0.0-alpha.299

## A call carries an identity

Every request now carries `id`, stamped by the caller in `Call.invoke` beside `source`,
`telemetry` and `trail`. Nothing an application writes has to change: `Request` means what it
always meant, and `id` is optional on it. What is new is `Envelope`, which is a `Request` whose
identity is settled — what an operation receives, and what the runtime hands to a binding.

A storage connector outside this repository sees a widened `Storage`: `store`, `upsert` and
`ensure` take one more argument, and two members are added.

```ts
store(record: Record, row?: Row, call?: Call): Promise<boolean>
upsert(query: Query, changeset: object, row?: Row, call?: Call): Promise<Record | null>
ensure(query, properties, record, row?: Row, call?: Call): Promise<Record>

readonly inbox?: Inbox
readonly claims?: boolean
```

A connector that ignores `call` and declares neither goes on working exactly as it did; a
component that asks it for `once` is refused at boot rather than started without the guarantee.

## `Call.invoke` no longer writes onto the request it is given

It builds the envelope around what it was handed. So a caller's own object no longer comes back
carrying `authentic`, `telemetry`, `source`, `trail`, a defaulted `input`, or the coercion the
request schema applied — none of which was ever declared, and none of which anything in this
repository read.

This is what makes an identity possible at all: one request object is handed to several
concurrent calls in more than one place, and an identity written onto it would make all but the
first of them a duplicate of the first.

## An operation may ask to run once

```yaml
# manifest.toa.yaml
operations:
  charge:
    type: transition
    scope: object
    concurrency: retry
    once: true
```

The same call arriving twice changes state once, and the second arrival is answered with what the
first one answered. See [the inbox](/documentation/inbox.md).

Two things to know before turning it on:

- **Every caller must be on this version or later.** A call from an older runtime carries no
  identity, and an operation that declares `once` refuses it — `RequestContract`, code `202`.
  Deploy the callers first.
- **The storage must have transactions.** MongoDB on a replica set or a sharded cluster; a
  standalone `mongod` refuses to boot the component rather than start it without the guarantee.

```yaml
# context.toa.yaml
inbox:
  retention: 3600 # seconds a call is remembered, which is how late a duplicate may arrive
```
