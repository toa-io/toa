# Migrating from 1.0.0-alpha.300

## A contract no longer takes a property from the entity by `default: .`

A property of an operation's input or output declared as a string with `default: .` was replaced
by the entity's property of the same name, and one with `default: .name` by the property named.
Neither is read any longer: such a property is a string whose default is `.`.

```yaml
# manifest.toa.yaml

entity:
  properties:
    title:
      type: string
      maxLength: 64

operations:
  transit:
    input:
      properties:
        title:
          type: string
          default: .
```

Repeat the entity's property with a YAML anchor:

```yaml
# manifest.toa.yaml

entity:
  properties:
    title: &title
      type: string
      maxLength: 64

operations:
  transit:
    input:
      properties:
        title: *title
```

An anchor is seen only in the file that declares it, so a property the manifest does not declare
itself — `id`, and the other system properties — is written out in full.
