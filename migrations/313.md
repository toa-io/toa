# Migrating from 1.0.0-alpha.313

## An inbox window is ten minutes at least

`inbox.retention` in a context is refused under `600`, where anything from `1` was accepted. So is
the window an operation may now state as the value of `once` — see
[the inbox](/documentation/inbox.md). The broker alone repeats a call for up to about ten minutes,
and a shorter window misses duplicates the runtime itself makes.

The calls already remembered need nothing: each expires when it would have.

## Trailers are written into `TRAILERS`

What a transition hands to the event of its commit is written into `state.TRAILERS`, where it was
`state._trailers`. The event still carries it as `trailers`, so an event bridge that reads
`event.trailers` is unchanged.

```js
export function transition(input, object) {
  object.TRAILERS.inc = input.inc

  return object
}
```

A transition that still writes into `_trailers` throws `Cannot set properties of undefined`.

`TRAILERS` is a system property: a component that declares an entity property of that name no
longer builds, and it may not be named in `blank`:

```
System property 'TRAILERS' cannot be declared
```

## What to do

1. Raise `inbox.retention` to `600` or more where a context states less.
2. Replace `_trailers` with `TRAILERS` in every transition.
3. Rename an entity property called `TRAILERS`, and the field the collection holds with a
   [migration](/documentation/component/declaration.md#migrations).
