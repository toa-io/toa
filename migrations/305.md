# Migrating from 1.0.0-alpha.305

## A call made through a component that has been taken down is refused

A component keeps its `context` for as long as its tree is up, and what a tree is taken down by is
a process shutting down or a [halt](/documentation/halt.md). A call made through such a context —
by an interval, a watcher, a promise nobody awaited — was served; it now throws `Disposed`, and a
rejection nobody handles ends the process as any other does.

What a component starts, it stops: an interval started in `preflight` is cleared in `dispose`, and
in `pause` where the deployment may be halted.

```javascript
// rc/poller.js

export function preflight(context) {
  context.state.poller = setInterval(() => poll(context), 1000)
}

export function dispose(context) {
  clearInterval(context.state.poller)
}
```

   a `context` it captured.
