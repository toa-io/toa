# Migrating from 1.0.0-alpha.321

## `IGNORED` is a system property

A transition that sets `state.IGNORED = true` commits nothing — see
[Transition](/documentation/design.md#transition). A component that declares an entity property of
that name no longer builds, and it may not be named in `blank`:

```
System property 'IGNORED' cannot be declared
```

## What to do

1. Rename an entity property called `IGNORED`, and the field the collection holds with a
   [migration](/documentation/component/declaration.md#migrations).
