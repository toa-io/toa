# Migrating to 1.0.0-alpha.277

Toa is ES modules.

## The packages are modules

Every `@toa.io/*` package declares `"type": "module"`. A CommonJS consumer on Node 24 requires
one as before, unless something in its graph awaits at the top level.

```javascript
const { Factory } = require('@toa.io/bridges.node')
```

```javascript
import { Factory } from '@toa.io/bridges.node'
```

A package's manifest resolves as it did — none of them declares `exports` — except
`@toa.io/userland`, which names `./stage`.

`@toa.io/runtime` and `@toa.io/prototype` have a real entry module in place of `"main":
"package.json"`, so `version` is a named export:

```javascript
const { version } = require('@toa.io/runtime/package.json')
```

```javascript
import { version } from '@toa.io/runtime'
```

## A component may be written either way

The Node bridge imports a component's modules, and importing a CommonJS one gives its
`module.exports` alongside the names Node can see in it. An operation, event, receiver, guard or
rc written as `exports.transition = transition` keeps working, and may now be written as
`export { transition }` or with a `.mjs` extension.

An operation module must export one algorithm. Where two exports were a function, the first
written won; a module namespace has no such order, so two is an error that says which they are.

A component written as a module states so the way any package does, in a `package.json` beside
its manifest:

```json
{
  "type": "module"
}
```

Without one it is read as CommonJS. `toa build` writes that file into the image for a component
that has none, stating the format the component was written under, so a component in a workspace
that is a module stays one when it is deployed.

## The runtime loads what it is told to, asynchronously

An extension, a binding, a bridge and a storage connector are imported rather than required. A
`Factory` that reaches for one may return a promise, and `toa.core.extensions.Factory` allows it:

```typescript
public tenant (locator: Locator, node: syntax.Node): Connector
public service (): Connector | null
```

```typescript
public async tenant (locator: Locator, node: syntax.Node): Promise<Connector>
public async service (): Promise<Connector | null>
```

## Tests run on `node:test`

Jest is gone, and with it `ts-jest` and `jest-esbuild`. `npm run test:unit` runs `node --test`
through `tsx`. A package that ran `jest` of its own defers to the root.

## Linting is oxlint, formatting is oxfmt

`.eslintrc.yaml` becomes `.oxlintrc.json`, and the JavaScript is linted where it was not before.
Four rules have no counterpart and are gone: `padding-line-between-statements`,
`newline-before-return`, `import/order` and `@typescript-eslint/member-ordering`.

## What to do

1. Import a Toa package rather than requiring it.
2. Read `version` from `@toa.io/runtime` rather than its manifest.
3. Give a component that is written as a module a `package.json` saying so.
4. Split an operation module that exports more than one algorithm.
5. Await a `Factory`'s `tenant` and `service` if you wrote an extension.
