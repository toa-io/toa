# Migrating to 1.0.0-alpha.276

The gateway answers its readiness probe on a port of its own, and can serve cleartext HTTP/2.

## The readiness probe moved to its own port

The exposition gateway serves `GET /.ready` on port `8004` instead of `8000`. The reserved ports are
now listed in [documentation/ports.md](../documentation/ports.md). It still answers
for the gateway itself — after route discovery settles and the server is listening — and
telemetry's probe stays disabled in that process, because telemetry's tracks the identity
composition nested there, which connects earlier.

A deployment picks the new port up on its own. Nothing in a context changes.

`/.ready` is no longer on the port the ingress routes to, so it is not reachable from outside
the cluster. An uptime check pointed at `https://<host>/.ready` must move to an endpoint the
application serves.

## HTTP/2

The exposition annotation takes `protocol`, either `h1` (the default, HTTP/1.1) or `h2c`
(cleartext HTTP/2).

```yaml
exposition:
  protocol: h2c
  service:
    annotations:
      projectcontour.io/upstream-protocol.h2c: "8000"
```

`h2c` requires an ingress controller that proxies cleartext HTTP/2 upstream. Contour, Traefik
and Envoy-based controllers do; ingress-nginx does not — its `proxy_pass` speaks HTTP/1.x, and
its only HTTP/2 path is `grpc_pass`. A cleartext HTTP/2 server cannot answer HTTP/1.1 on the
same port, so a controller that downgrades reaches nothing.

Under `h2c` a request refused before its body is read is answered and then cancelled with
`RST_STREAM(NO_ERROR)`: the reply arrives, and the upload stops. A client streaming a request
body sees that body cancelled — in Node as `ERR_STREAM_PREMATURE_CLOSE` on the stream it
passed, which throws if nothing handles it. It is not a failure on its own: a real one shows
in the reply, or in the request rejecting because no reply came.

```javascript
const body = createReadStream(path)

body.on('error', () => undefined)

const response = await fetch(url, { method: 'PUT', body, duplex: 'half' })
```

A client sending a buffered body is unaffected.

## Service annotations

A service takes `annotations` of its own, applied to the `Service`, beside the
`ingress.annotations` applied to the `Ingress`. The exposition annotation exposes them under
`service`.
