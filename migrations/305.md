# Migrating from 1.0.0-alpha.305

## A call made through a component that has been taken down is refused

A component keeps its `context` for as long as its tree is up, and what a tree is taken down by is
a process shutting down or a [halt](/documentation/halt.md). A call made through such a context —
by an interval, a watcher, a promise nobody awaited — was served; it now throws `Disposed`, and a
rejection nobody handles ends the process as any other does.

What a component starts, it stops: an interval started in `preflight` is cleared in `dispose`, and
in `pause` where the deployment may be halted.

```javascript
// rc/poller.js

export function preflight(context) {
  context.state.poller = setInterval(() => poll(context), 1000)
}

export function dispose(context) {
  clearInterval(context.state.poller)
}
```

## A `Safety` refusal carries code `406`

A call to an operation that may change state, made under a request that may only read, is refused
with `406` where it was `700`. It reads as what it is — a call that was refused rather than a
class of its own — beside the other refusals of a call, and nothing else about it changed: it is
still permanent, and still answered `500` over HTTP.

## Introspection records that a call was made, never what it carried

The map holds the pair a call connects and nothing else. `introspection.samples` is read by
nothing — in `context.toa.yaml` and in a component's `manifest.toa.yaml` alike — and an edge has
no `sample`, so a reader of `GET /introspection/edges/` no longer finds one. A component that
declared `samples: false` because it handles personal data has what it asked for unconditionally,
and the samples already stored are read by nothing.

## A process is given the versions of the components it asks

`toa compose`, `toa serve` and `toa mono` read a `components.json`, which `toa map` writes from a
Context. It is found from the working directory upwards, the way `.env` is, or named with `--map`,
and a run is refused where a Context is there and its map is not. A component run outside a
Context has no peers a map could name, and needs none.

```shell
$ toa map -p application
$ toa compose ./application/components/* --env application/.env --map application/components.json
```

Write it beside whatever already writes the environment — an `env` script, a process supervisor,
an image entrypoint — and write it again when a component's sources change: a version is a hash of
them, and a map naming one nothing runs is a lookup that waits, saying every five seconds which
component and which version it is waiting for.

`toa deploy` writes the map it deploys and mounts it on every workload, so a deployed application
has nothing to do. **Upgrade the whole Context before running a process of this release beside
it**: a process of this release asks a component for a named version, and a peer of an earlier one
does not answer that.

See [contracts](/documentation/contracts.md).

1. Clear in `dispose` what a run command started, and take hold of anything else that calls through
   a `context` it captured.
2. Read `406` where a caller matched `700` for a readonly refusal.
3. Delete `introspection.samples` from your context and from any manifest that declares it.
4. Run `toa map` wherever `toa env` is run, and pass `--map` where `--env` is passed.
