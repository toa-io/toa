# Migrating from 1.0.0-alpha.328

## A range of addresses is written in brackets, and its end is exclusive

A range in an address of a Context — a broker, a database, a Redis — is written `[0..3]`, where
it was `{0-2}`. It is the range comq reads, so an address is written one way wherever it is
written.

```yaml
amqp:
  context: amqp://rmq[0..3].example.com # was amqp://rmq{0-2}.example.com
```

- **The end is exclusive.** `[0..3]` is `0`, `1` and `2`: a range that starts at zero names as
  many hosts as its end says. `{1-3}` is written `[1..4]`.
- **A start with leading zeros pads every number to its width**: `[00..32]` is `00` to `31`.
- **A range is read in the host alone**, and a host may hold several.

A range left in braces is no longer a range: the address is refused as one that is not a URI.
