# Migrating from 1.0.0-alpha.328

## A range of addresses is written in brackets, and its numbers are padded

A range in an address of a Context — a broker, a database, a Redis — is written `[0..31]`, where
it was `{0-31}`, and every number is as wide as the end of the range:

```yaml
amqp:
  context: amqp://rmq[0..31].example.com # rmq00 … rmq31 — {0-31} was rmq0 … rmq31
```

- **A range whose end has more than one digit names other hosts than it did**: `rmq00`, where it
  was `rmq0`. Rename the hosts, or list the addresses that keep their names.
- **A range is read in the host alone**, and a host may hold several.
- **A range that does not end above where it starts is refused.**

A range left in braces is no longer a range: the address is refused as one that is not a URI.
